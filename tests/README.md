# Tests

The project currently includes a manual smoke-test checklist. Automated GDScript tests are planned for the next milestone.

## Smoke test
1. Open `project.godot` in Godot 4.3 or newer.
2. Run the main scene.
3. Confirm the third-person camera follows the player.
4. Move with WASD, jump with Space, sprint with Shift.
5. Aim with the mouse and fire with left click.
6. Reload with R.
7. Confirm the enemy follows and attacks within range.
8. Confirm the HUD reports health, armor, ammunition and eliminations.

No test is marked as passed until it has actually been run on the target engine/device.
