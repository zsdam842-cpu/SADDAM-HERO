# SADDAM HERO — Saddam-Battle
مشروع لعبة أكشن ثلاثية الأبعاد أصلية باستخدام Godot 4 وGDScript. هذه نسخة تأسيسية قابلة للتطوير وليست اللعبة المكتملة.

## الحالة
- لاعب منظور ثالث بحركة ومشي وجري وقفز وانحناء.
- كاميرا خلف اللاعب.
- سلاح hitscan مع مخزن وذخيرة وإعادة تلقيم.
- عدو أولي يطارد اللاعب ويهاجمه.
- صحة ودرع وواجهة معلومات.
- بيانات حملة أولية من 12 مهمة.
- إعداد أولي لـ GitHub Actions.

## التشغيل
افتح `project.godot` في Godot 4.3+ وشغّل المشهد الرئيسي.
تحكم لوحة المفاتيح: WASD، Shift للجري، Space للقفز، C للانحناء، R للتلقيم، زر الفأرة الأيسر للإطلاق، Esc لتحرير المؤشر.

## Android
استخدم GL Compatibility. يلزم تثبيت Android SDK/JDK وقوالب تصدير Godot وإعداد Android Export Preset قبل إنتاج APK. لم يتم إنتاج APK أو اختباره في هذه النسخة.

## غير المنفذ بعد
المركبات والدراجات والمروحيات، حملة 12 مهمة قابلة للعب، ENet multiplayer بخمسة أجهزة، الحفظ النهائي، اللمس، الصوت، تحسين الأداء واختبارات الأجهزة. لا تدّعي هذه النسخة اكتمالها.

الأصول الحالية أشكال Godot أولية. لا تتضمن أصولاً من ألعاب أخرى.
