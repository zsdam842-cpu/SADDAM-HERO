# SADDAM HERO — Saddam-Battle

مشروع لعبة أكشن عسكرية ثلاثية الأبعاد أصلية باستخدام Godot 4 وGDScript، مع نموذج أولي قابل للتوسعة.

## الحالة الحالية

هذه الحزمة هي **المرحلة التأسيسية / نموذج لعب أولي** وليست اللعبة النهائية المكتملة. تحتوي على:
- مشروع Godot 4 مضبوط على Mobile/GL Compatibility.
- لاعب منظور ثالث: حركة، جري، قفز، انحناء، كاميرا وتحكم فأرة.
- سلاح hitscan مع ذخيرة ومخزن وإعادة تلقيم.
- عدو أولي يكتشف اللاعب ويطارده ويهاجمه.
- صحة ودرع وإعادة تشغيل عند نفاد الصحة.
- HUD يعرض الصحة والدرع والذخيرة وعدد الإقصاءات.
- بيانات حملة من 12 مهمة كبنية بيانات أولية.
- GitHub Actions للاستيراد وفحص بدء التشغيل ومحاولة تصدير Android.

## التشغيل

1. ثبّت Godot Engine 4.3 أو أحدث.
2. افتح `project.godot`.
3. شغّل المشهد الرئيسي.
4. عناصر التحكم:
   - WASD: الحركة
   - Shift: الجري
   - Space: القفز
   - C: الانحناء
   - Mouse: توجيه الكاميرا
   - Left Click: إطلاق النار
   - R: إعادة التلقيم
   - Esc: تحرير مؤشر الفأرة

## Android

تم ضبط العرض على GL Compatibility المناسب كبداية للأجهزة المحمولة. يلزم تثبيت Android SDK/JDK وقوالب تصدير Godot وإعداد Export Preset باسم `Android` قبل إنتاج APK. لا يوجد APK مرفق لأن التصدير لم يُنفّذ في بيئة بناء فعلية.

## خارطة الطريق

1. تأسيس المشروع وإعداد Android — بدأ.
2. اللاعب والكاميرا — نموذج أولي.
3. الأسلحة والقتال — سلاح hitscan أولي؛ يلزم التوسّع.
4. ذكاء الأعداء — مطاردة وهجوم أوليان.
5. الخرائط والمهام — بيانات 12 مهمة؛ يلزم بناء محتواها.
6. السيارات والدراجات — لم تنفذ بعد.
7. المروحيات — لم تنفذ بعد.
8. اللعب الجماعي المحلي — لم ينفذ بعد.
9. مزامنة المركبات الجماعية — لم تنفذ بعد.
10. الواجهة والصوت والحفظ — HUD أولي؛ الباقي قيد التطوير.
11. تحسين الأداء — إعدادات أولية؛ يلزم profiling على الأجهزة.
12. الاختبارات وإنتاج APK — workflow مبدئي؛ لم يتم التحقق من APK.

## اللعب الجماعي

لم تتم إضافة شبكة ENet بعد. لا يُدّعى دعم اللعب الجماعي أو اختباره على خمسة أجهزة في هذه النسخة.

## الأصول والترخيص

المشهد التجريبي يستخدم أشكال Godot البدائية فقط، ولا يتضمن أصولاً من ألعاب أخرى. جميع الأصول المستقبلية يجب أن تكون أصلية أو مرخصة.
